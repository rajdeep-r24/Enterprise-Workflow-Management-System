1. Multi-Tenant Isolation Architecture

Anukram enforces strict organization data boundaries at both the application middleware layer and the database query layer:

  • Tenant Resolution Middleware: Resolves the authenticated user's organization on every request and assigns request.tenant.
  • Scoped Tenant Managers: All models inherit from TenantManager / TenantQuerySet providing .for_tenant(organization), ensuring queries cannot leak foreign records.
  • Automated Isolation Test Suite: Cross-tenant access attempts return HTTP 404 / 403 and are covered by automated unit tests.
Incoming Request → TenantMiddleware (Resolves request.tenant) → Model.objects.for_tenant(request.tenant) → Isolated Record Set

2. Deterministic Multi-Tier State Machine

Requests transition deterministically through defined stages protected by atomic database row locking (select_for_update) to prevent race conditions:

Role Hierarchy Level Responsibilities
EMPLOYEE Level 1 Submit dynamic requests, upload attachments, track status, add request notes.
MANAGER / IT_HEAD / HR_HEAD / UNIT_HEAD Level 2–4 Review assigned steps, approve/reject with timestamped remarks, download personal history.
ORG_ADMIN / ADMIN Level 5 Configure workflows, build forms, manage employees, revoke permissions, export full audit CSVs.

3. QR Token Generation & Audit Trail

Upon final step approval, Anukram generates an unguessable UUIDv4 verification token and official ReportLab PDF voucher:

  • Live QR Validation: Physical gate security or auditors scan the QR code to verify token validity in real-time at /verify/{token}/.
  • Revocation Control: Administrators can revoke permissions instantly with a recorded revocation reason.
  • Append-Oriented Audit Logs: Every submission, step assignment, approval, remark, and rejection generates an event row in WorkflowEvent exported in UTF-8 BOM CSV format for compliance reviews.

4. File Security & API Reference

Uploaded attachments undergo strict validation:

  • Extension & Size Checks: Enforces ≤ 10MB limit and restricts uploads strictly to safe document and image formats.
  • Binary Magic Byte Inspection: Blocks disguised executable binaries (PE, ELF) and embedded scripts.
  • Object-Level Access: Attachment downloads are authorized strictly to the request owner, assigned approver, or organization admin.
