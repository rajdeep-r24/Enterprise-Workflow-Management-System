FAQ

Straight answers

How does automatic routing actually work?
You define approval workflows per request type, specifying which role or department should approve each step. Anukram reads the requester's profile at submission time and resolves the correct approver automatically. No manual forwarding, ever.
Can we have different approvers per department?
Yes. Workflows are fully configurable per request type and can route to different approvers based on the requester's department, designation, or location. The engine resolves the correct approver at runtime.
What if an approver doesn't respond?
Requests remain in the approver's inbox until actioned. You can configure escalation contacts within your organization for time-sensitive requests that need manual intervention.
Are the QR slips actually verifiable?
Yes. Each QR code encodes a signed token tied to the specific approved request. Security staff scan the code and immediately see the approval status, approver identity, and expiry without calling anyone.
Is our data completely isolated from other organizations?
Absolutely. Anukram is a fully multi-tenant platform. Every organization's data is isolated at the database level. No organization can ever see another's data.
